# SKU Demand Forecasting - Final Reproduction

## 1. Project Overview
This repository reproduces the final Kaggle submissions for a daily SKU demand forecasting task. The data is intermittent and long-tail heavy, so the final approach combines a recent-window anchor forecast with controlled long-tail suppression and Sunday-zero postprocessing.

## 2. Final Selected Submissions

## 6. Method Summary

- Clean the raw transaction table and build a daily SKU panel.
- Compute SKU-level activity and profit rank from the training period.
- Build the anchor forecast from recent windows `14`, `18`, and `21` days using weights `0.20`, `0.45`, and `0.35`.
- Force Sunday forecasts to zero in the forecast horizon.
- Suppress long-tail and intermittent SKUs more aggressively as rank worsens and recency/activity weaken.
- Keep rank `<= 500` exactly equal to the anchor forecast.
- Clip negative values to zero after candidate rules.

## 7. QA and Reproducibility Checks

The final script checks:

- exact sample id order
- exact sample shape `(31944, 29)`
- no missing values
- no infinite values
- no negative forecasts
- Sunday columns `F2`, `F9`, `F16`, and `F23` sum to zero for validation and evaluation rows
- rank `<= 500` remains unchanged versus the anchor
- no recently active long-tail SKU is zeroed out
